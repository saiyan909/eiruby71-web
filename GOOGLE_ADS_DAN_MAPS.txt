PANDUAN MENGGANTI DOMAIN JADI eiruby71.com (CUSTOM DOMAIN)
================================================================================
Jika nanti kamu atau om kamu sudah membeli domain (misal: eiruby71.com atau eiruby71.my.id):

1. Masuk ke dashboard penyedia domain (Niagahoster / Domainesia / Rumahweb / Namecheap).
2. Masuk ke menu "DNS Management" pada domain tersebut.
3. Tambahkan 4 buah DNS A-Record ke IP GitHub Pages berikut:
   Type: A  |  Host: @  |  Value: 185.199.108.153
   Type: A  |  Host: @  |  Value: 185.199.109.153
   Type: A  |  Host: @  |  Value: 185.199.110.153
   Type: A  |  Host: @  |  Value: 185.199.111.153

4. Tambahkan 1 buah CNAME Record untuk www:
   Type: CNAME  |  Host: www  |  Value: saiyan909.github.io

5. Di repo GitHub:
   Buka Settings -> Pages -> Custom domain -> masukkan `eiruby71.com` -> Klik Save.
   Centang pilihan "Enforce HTTPS".

Selesai! Web akan otomatis beralih menjadi https://eiruby71.com tanpa biaya hosting selamanya.
